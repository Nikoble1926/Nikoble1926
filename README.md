### 🛠️ What I build

- **Pay-per-call services for AI agents** over the **x402** protocol (HTTP 402, USDC on Base/Pharos) — crypto market-state signals, regime skills, ERC-8004 trust scores.
- **Autonomous multi-agent workflows** — e.g. a veto-loop enterprise approval desk (Analysis · Advisor · Risk/Compliance).
- **Open data & SEO web** — independent plug-in/balcony solar guides (US & UK) with a free 50-state legality **dataset/API** (merged into awesome-public-datasets).
- I ship fast, **AI-augmented**, end-to-end: code → deploy → SEO → monetize.
